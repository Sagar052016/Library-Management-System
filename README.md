# Library Management System 📚

A simple and interactive Library Management System developed using HTML, CSS, and JavaScript. It helps users manage library books and track their availability.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Add new books
- Display book details
- Search books by title or author
- Issue books
- Return issued books
- Delete book records
- Responsive user interface

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Start managing your books.
